# Vinas

深緑の茄子茶入を、障子の光が差す静かな茶室で鑑賞するデスクトップアプリです。
回転させると釉薬の斑と光の映り込みの見え方が変わります。
オリジナルBGM「Between Breaths」は、弦、息の音、鐘をイメージした音色でゆっくりと巡ります。

## 起動

- **Appleシリコン Mac（macOS 12以降）**。Finderから開く場合は `Vinas-macOS-AppleSilicon.zip` を展開して `Vinas.app` を開きます。
- **Windows 10 / 11（x64）**。`Vinas-Windows-x64.zip` を展開して`Vinas.exe` を開きます。

3Dモデル、背景、BGM、アイコンは実行ファイルに組み込まれています。ネット接続や追加の素材ファイルは不要です。配布用のMac版にはアドホック署名を付けています。Developer ID署名とAppleの公証は付いていません。Windows版は自己署名を付けています。

## 操作

| 操作 | マウス | キーボード |
| --- | --- | --- |
| 手動で縦横360°回転 | 画面をドラッグ | 矢印キー |
| 拡大・縮小 | ホイールまたはトラックパッド | ＋ / − |
| 自動回転と手動鑑賞の切り替え | Auto-rotate / Pause rotation | Space |
| フルスクリーンの切り替え | Full screen / Exit full screen | F または F11 |
| UIを隠す・再表示する | Hide UIで隠す。右クリックで戻す | Hで切り替え。Escで戻す |
| 視点を初期位置に戻す | Reset view またはダブルクリック | R または 0 |
| BGMのオン・オフ | Sound on / Sound off | M |
| 音量 | 右下のスライダー | — |

手動鑑賞では茶入が畳から浮き、上下に回して蓋や底面まで見られます。自動回転では茶入が畳に戻り、ゆっくり水平に回ります。UIを隠している間も回転、ズーム、BGM、フルスクリーンのショートカットを使えます。EscはUIが隠れている場合はUIを戻し、UIが表示されている場合はフルスクリーンを解除します。
